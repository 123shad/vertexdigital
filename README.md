# Nexus College Website

A modern responsive college website concept created as a web-development portfolio project.

## Features
- Responsive modern UI
- College hero and admissions CTA
- About section
- Academic programs
- Department directory
- Notices and events
- Admissions section
- Contact information
- WhatsApp and email CTAs
- Mobile navigation
- Smooth scrolling
- No backend required

## Tech
HTML5, CSS3, JavaScript, Google Fonts, Font Awesome

## Deployment
Upload `index.html` to a GitHub repository and enable GitHub Pages from the `main` branch and `/ (root)` folder.
