# Vertex Digital — Company Website

A premium responsive technology-company website concept with a clean white interface and modern blue-purple-cyan gradients.

## Features
- White corporate UI with gradient accents
- Responsive navigation
- Hero section with dashboard-style visual
- Services grid
- Company/about section
- Development process
- Gradient conversion CTA
- Contact section
- WhatsApp and email CTAs
- Responsive mobile navigation
- CSS-only visual elements
- GitHub Pages ready

## Tech Stack
HTML5, CSS3, JavaScript, Google Fonts, Font Awesome
